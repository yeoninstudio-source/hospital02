# 피부과 클리닉 사이트 템플릿

mimodern.co.kr의 **구조/레이아웃/인터랙션**을 참고해 만든 정적 사이트 템플릿입니다.
원본의 텍스트, 이미지, 로고, 브랜드명은 저작권 보호 대상이므로 사용하지 않았고,
모두 자체 작성한 더미 콘텐츠와 CSS 그라디언트 플레이스홀더로 대체했습니다.

## 실행

`index.html`을 브라우저로 바로 열면 됩니다. (외부 라이브러리 없음, 빌드 불필요)

로컬 서버로 보려면:

```bash
npx serve C:/Users/USER/clinic-clone
```

## 파일 구조

```
clinic-clone/
├─ index.html          모든 마크업 (섹션별 주석 구분)
└─ assets/
   ├─ css/style.css    변수 → 리셋 → 섹션별 → 반응형 순
   └─ js/main.js       팝업 / 헤더 / 사이트맵 / 리빌 / 카운터 / 캐러셀
```

## 구현된 것

| 영역 | 내용 |
|---|---|
| 헤더 | 스크롤 시 배경 전환, 하향 스크롤 시 숨김, 데스크톱 메가 드롭다운, LINE UP 바 |
| 전체 메뉴 | GNB DOM을 JS로 복제해 사이트맵 자동 생성 (메뉴 추가 시 자동 반영) |
| 메인 팝업 | "하루동안 보지 않기" → `localStorage` 24시간 저장, ESC / 배경 클릭 닫기 |
| 메인 비주얼 | 풀스크린, 그라디언트 오브 애니메이션, 스크롤 인디케이터 |
| 캐러셀 | 자체 구현. 드래그·스와이프, 브레이크포인트별 노출 개수, 루프, 자동재생, 진행 바 |
| 의료진 | `background-attachment: fixed` 패럴랙스 + 숫자 카운트업 |
| 전후사진 | 카드 클릭 시 Before ↔ After 크로스페이드 |
| 기타 | 스크롤 진행 바, IntersectionObserver 리빌, 퀵메뉴 접기, 모바일 하단 바, 앵커 헤더 보정 |
| 접근성 | `prefers-reduced-motion` 대응, `aria-expanded`/`aria-label`, 키보드 포커스 대응 |

반응형 브레이크포인트: 1400 / 1200(GNB → 사이트맵 전환) / 1024 / 768(모바일 바) / 480

## 교체해야 할 플레이스홀더

- **브랜드**: `LUMINA` / `루미나피부과의원` → 실제 상호. 로고는 `index.html`의 인라인 SVG(`.logo-mark`) 교체
- **연락처**: `02-000-0000`, `tel:0200000000`, `hello@example.com`
- **주소·사업자정보**: `○○구 ○○로 000`, 사업자등록번호, 대표자명 (푸터 `.ft-meta`)
- **이미지**: 그라디언트 블록(`.prog-card`, `.spec-visual`, `.doc-photo`, `.ba-img`, `.yt-thumb`)을 `<img>`로 교체.
  각 요소의 `--c1`/`--c2` 인라인 변수가 색상 지정용이므로 함께 제거
- **지도**: `.loc-map` 영역을 카카오맵/네이버맵 임베드로 교체
- **색상**: `style.css` 최상단 `:root` 변수 (`--brand`, `--accent` 등)
- **폰트**: Google Fonts에서 Noto Sans KR + Cormorant Garamond 로드 중
